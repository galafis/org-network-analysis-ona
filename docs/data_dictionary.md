# Data Dictionary — ONA Platform

## Input Data Models

### Employee Profile

Generated by `src/data/generator.py` — `ONADataGenerator.generate_employees()`

| Field          | Type   | Description                                       | Example         |
|----------------|--------|---------------------------------------------------|-----------------|
| `employee_id`  | str    | Unique employee identifier                        | `EMP-0042`      |
| `name`         | str    | Full name (synthetic, Brazilian naming patterns)   | `Ana Silva`     |
| `department`   | str    | Organizational department (8 departments)          | `Engineering`   |
| `seniority`    | str    | Seniority level (6 levels)                         | `Senior`        |
| `tenure_years` | float  | Years at the company (exponential distribution)    | `3.5`           |
| `location`     | str    | Work location                                     | `HQ-SP`         |

#### Department Values

| Department   | Approximate Weight |
|--------------|-------------------|
| Engineering  | 25%               |
| Product      | 12%               |
| Sales        | 15%               |
| Marketing    | 10%               |
| HR           | 8%                |
| Finance      | 10%               |
| Operations   | 12%               |
| Legal        | 8%                |

#### Seniority Levels

| Level    | Approximate Distribution |
|----------|-------------------------|
| Junior   | 25%                     |
| Mid      | 30%                     |
| Senior   | 25%                     |
| Lead     | 12%                     |

| VP       | 2%                      |

#### Location Values

### Interaction Record

Generated by `src/data/generator.py` — `ONADataGenerator.generate_interactions()`

| Field       | Type | Description                                   | Example   |
|-------------|------|-----------------------------------------------|-----------|
| `source_id` | str  | Employee ID of interaction initiator           | `EMP-0012`|
| `target_id` | str  | Employee ID of interaction recipient           | `EMP-0087`|
| `channel`   | str  | Communication channel                          | `slack`   |
| `month`     | int  | Month number within the analysis window        | `3`       |
| `weight`    | int  | Interaction count (Poisson-distributed)         | `4`       |

#### Channel Types

| Channel   | Base Probability | Description          |
|-----------|-----------------|----------------------|
| `slack`   | 0.15            | Instant messaging    |
| `email`   | 0.10            | Email communication  |
| `meeting` | 0.08            | Meetings             |

#### Interaction Probability Modifiers

| Condition                          | Multiplier |
|------------------------------------|-----------|
| Same department                    | 3.0x      |
| Senior employee + cross-department | 1.5x      |

## Output Data Models

Defined in `src/api/schemas.py`.

### GraphStatsOut

Graph-level summary statistics.

| Field                    | Type       | Description                                |
|--------------------------|------------|--------------------------------------------|
| `n_nodes`                | int        | Total employees in the graph               |
| `n_edges`                | int        | Total communication edges                  |
| `density`                | float      | Graph density [0.0, 1.0]                   |
| `avg_clustering`         | float      | Average clustering coefficient             |
| `n_connected_components` | int        | Number of connected components             |
| `avg_degree`             | float      | Average node degree                        |
| `diameter`               | int | None | Diameter of the largest connected component|

### BottleneckOut

Employees identified as information bottlenecks.

| Field                    | Type  | Description                                           |
|--------------------------|-------|-------------------------------------------------------|
| `employee_id`            | str   | Employee identifier                                    |
| `betweenness`            | float | Betweenness centrality score                           |
| `degree`                 | int   | Node degree (total connections)                        |
| `departments_connected`  | int   | Number of distinct departments connected               |
| `risk_level`             | str   | CRITICAL, HIGH, MODERATE, or LOW                       |
| `reason`                 | str   | Human-readable explanation of bottleneck classification|

### KnowledgeRiskOut

Employees whose departure would cause knowledge loss.

| Field                    | Type  | Description                                    |
|--------------------------|-------|------------------------------------------------|
| `employee_id`            | str   | Employee identifier                             |
| `department`             | str   | Employee department                             |
| `seniority`              | str   | Employee seniority level                        |
| `tenure_years`           | float | Years at the company                            |
| `unique_connections`     | int   | Number of unique employees connected            |
| `knowledge_score`        | float | Composite knowledge risk score [0.0, 1.0]      |
| `risk_level`             | str   | CRITICAL, HIGH, MODERATE, or LOW                |
| `replacement_difficulty` | str   | Estimated difficulty of replacing this employee |

### CommunityOut

Communities detected via the Louvain algorithm.

| Field                | Type          | Description                                      |
|----------------------|---------------|--------------------------------------------------|
| `community_id`       | int           | Unique community identifier                       |
| `size`               | int           | Number of members                                 |
| `dominant_department` | str          | Department with the most members in the community |
| `cross_department`   | bool          | Whether the community spans multiple departments  |
| `departments`        | dict[str,int] | Department name to member count mapping           |

### RecommendationOut

Executive-level action items derived from analysis.

| Field          | Type       | Description                                       |
|----------------|------------|---------------------------------------------------|
| `priority`     | str        | HIGH, MEDIUM, or LOW                               |
| `category`     | str        | Category (e.g., Knowledge Transfer, Silo Breaking)|
| `title`        | str        | Short recommendation title                         |
| `description`  | str        | Detailed recommendation description                |
| `action_items` | list[str]  | Specific actionable steps                          |

### AnalysisResponse

Full analysis response combining all output models.

| Field              | Type                   | Description                    |
|--------------------|------------------------|--------------------------------|
| `graph_stats`      | GraphStatsOut          | Network-level statistics        |
| `bottlenecks`      | list[BottleneckOut]    | Detected bottleneck employees   |
| `knowledge_risks`  | list[KnowledgeRiskOut] | Knowledge loss risk assessments |
| `communities`      | list[CommunityOut]     | Detected communities            |
| `recommendations`  | list[RecommendationOut]| Executive recommendations       |
| `risk_score`       | int                    | Composite risk score (0-100)    |
| `summary`          | str                    | Executive summary narrative     |
